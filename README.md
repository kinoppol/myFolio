# E-Portfolio — นายนพพล อินศร

พอร์ตโฟลิโอออนไลน์สไตล์ **Liquid Glass** สำหรับ ครูชำนาญการ แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยอาชีวศึกษาร้อยเอ็ด
ออกแบบเต็มรูปแบบด้วย HTML / CSS / JavaScript (ไม่มีไลบรารีภายนอก) รองรับมือถือและเดสก์ท็อป

## ▶ วิธีเปิดใช้งาน
วางโฟลเดอร์นี้ไว้ที่ `C:\xampp\htdocs\myFolio` (โปรเจกต์ XAMPP)
แล้วเปิดเบราว์เซอร์ที่: **http://localhost/myFolio** (หรือเปิด `index.html` ตรง ๆ ก็ได้)
ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Google (Kanit + Outfit)

## ✏️ สิ่งที่ควรแก้ไขก่อนใช้งานจริง (ค้นหาใน `index.html`)
| ค่า | ที่ค้น | ตัวอย่างปัจจุบัน |
|---|---|---|
| อีเมล | `noppol@example.ac.th` | ใช้ 2 จุด (ข้อมูลติดต่อ + ฟอร์มส่งข้อความ) |
| โทรศัพท์ | `0XX-XXX-XXXX` | หมายเลขจริง |
| รูปโปรไฟล์ | `466835126_...n.jpg` | เปลี่ยนชื่อไฟล์/วางรูปใหม่แทน |
| สถิติใน Hero | `data-count="10"` `25` `500` `6` | ตัวเลขจริง |
| ปีในไทม์ไลน์ | `2562 / 2564 / 2566` | แก้ให้ตรงประวัติจริง |
| โซเชียลลิงก์ | `href="#"` ในส่วน socials | ใส่ URL จริง (FB / Line / อีเมล) |
| ชื่อหลักสูตรอบรม | เลขที่ `1371/2569` AI ณ เดอะ เล็กกาซี | แก้/เพิ่มตามวุฒิบัตรจริง |

## 🎨 ฟีเจอร์หลัก
- **Liquid Glass UI** — แผ่นกระจกเบลอ + โครงลวดลายแสง + เทกซ์เจอร์เกรนฟิล์ม
- **Liquid blob** — ก้อนของเหลว morph ด้านหลัง Hero + เอฟเฟกต์ wrinkle ด้วย SVG filter (goo / displacement)
- ออร์บไล่สี Aurora ขยับได้ เอฟเฟกต์ cursor แบบกำหนดเอง + แสงตามเมาส์
- พิมพ์หัวข้อแบบ typewriter, นับเลขสถิตินับขึ้น, แถบสกิลแอนิเมชัน, แถบเลื่อน Tech-Stack
- Reveal-on-scroll (IntersectionObserver + fallback), การ์ด tilt 3D, เอฟเฟกต์ shine
- แถบเมนูแก้วลอย + scrollspy, preloader, ปุ่มขึ้นด้านบน, รองรับ `prefers-reduced-motion`

## 🗂 โครงสร้าง
```
myFolio/
├── index.html          ← เว็บเพจเดียวครบทุกอย่าง (CSS + JS ในไฟล์เดียว)
└── <รูปโปรไฟล์>.jpg     ← รูปโปรไฟล์ 200x200
```

*สร้างโดยใช้ AI — เนื้อหาส่วนตัว/ตัวเลข/ประวัติ/วุฒิบัตร ควรตรวจสอบและแก้ไขให้ตรงข้อมูลจริงของเจ้าของ*
